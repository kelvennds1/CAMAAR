    Service for creating evaluation batches from a template. Creates one Avaliacao per selected Turma, copying questions from the template.

    Usage¶ ↑

    result = EvaluationBatchCreator.call(
  template_id: 1,
  turma_ids: [1, 2, 3],
  due_date: "2024-12-31"
)

if result.success?
  puts "Created: #{result.created.size}, Skipped: #{result.skipped.size}"
else
  puts "Errors: #{result.errors.join(', ')}"
end
    =======

    Service for creating batches of evaluations from templates. Creates multiple Avaliacao records and their associated Questao records for multiple classes (turmas) at once.
